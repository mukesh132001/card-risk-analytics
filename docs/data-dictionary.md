# Data dictionary

Generated by `python -m card_analytics.catalog` from `src/card_analytics/catalog.py`. Edit that file, not this one.

**PII classes:** `identifier` = direct ID, tokenised in the reporting layer · `quasi` = could help re-identify someone combined with other fields; the precise ones (birth date, exact age) are dropped from the reporting layer · `masked` = token that replaces an identifier · `-` = not personal.

Analysts and dashboards read the `rpt_` tables plus `dim_date` and `dim_district` (no personal data). The star-schema tables with raw IDs stay restricted.
